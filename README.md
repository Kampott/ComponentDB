# pg-client
PostgreSQL web-based abstraction layer

## Setup:
### 1. Environmental variables file
Set environmental variables in the `.env` file.
 Current Environmental variables: `BACKEND_PORT`, `FRONTEND_PORT`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`.
### 2. Install by running in tty in pg-client directory:
`docker compose up --build -d`
### 3. To shut off the webapp:
`docker compose down`
