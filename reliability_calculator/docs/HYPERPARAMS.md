# Гиперпараметры fake-генераторов

В этом файле описаны гиперпараметры генератора тестовых данных в памяти  
Все поля задаются явно через агрегатную инициализацию  
`seed` задается отдельно в конструкторе `FakeDatasetBuilder(seed)`

## Правило активности экземпляров

- Все экземпляры создаются как активные
- `isActive=false` выставляется только когда для экземпляра создается replacement-событие
- При replacement создается новый экземпляр с новым `id`, а старый становится неактивным

## TypeTreeHyperParams

| Параметр             | Тип             | Описание                                                     | Ограничения             |
|----------------------|-----------------|--------------------------------------------------------------|-------------------------|
| `depth`              | `std::uint32_t` | Количество уровней дерева типов включая корень               | `>= 1`                  |
| `minChildrenPerType` | `std::uint32_t` | Минимальное число дочерних типов у каждого нелистового узла  | `<= maxChildrenPerType` |
| `maxChildrenPerType` | `std::uint32_t` | Максимальное число дочерних типов у каждого нелистового узла | `>= minChildrenPerType` |

## ObjectTreeHyperParams

| Параметр                 | Тип             | Описание                                                                            | Ограничения                 |
|--------------------------|-----------------|-------------------------------------------------------------------------------------|-----------------------------|
| `minObjectsPerChildType` | `std::uint32_t` | Минимальное число объектов каждого дочернего типа под каждым родительским объектом  | `<= maxObjectsPerChildType` |
| `maxObjectsPerChildType` | `std::uint32_t` | Максимальное число объектов каждого дочернего типа под каждым родительским объектом | `>= minObjectsPerChildType` |

## InstanceTreeHyperParams

| Параметр             | Тип             | Описание                                                                     | Ограничения |
|----------------------|-----------------|------------------------------------------------------------------------------|-------------|
| `treesPerObjectRoot` | `std::uint32_t` | Количество полных деревьев экземпляров для каждого корневого дерева объектов | `>= 1`      |

## EventGenerationHyperParams

| Параметр                 | Тип                                     | Описание                                                                        | Ограничения                 |
|--------------------------|-----------------------------------------|---------------------------------------------------------------------------------|-----------------------------|
| `startTime`              | `std::chrono::system_clock::time_point` | Начало окна генерации синтетических событий                                     | Корректное значение времени |
| `window`                 | `std::chrono::hours`                    | Длительность окна генерации событий                                             | `> 0`                       |
| `baseFailureRatePerDay`  | `double`                                | Базовая пуассоновская интенсивность отказных замен на день для глубины `0`      | Практически `>= 0`          |
| `depthFailureRateFactor` | `double`                                | Мультипликативный коэффициент интенсивности отказов на каждый уровень глубины   | Практически `>= 0`          |
| `preventiveRateFactor`   | `double`                                | Отношение среднего числа профилактических замен к среднему числу отказных замен | Практически `>= 0`          |
| `inspectionRatePerDay`   | `double`                                | Пуассоновская интенсивность событий инспекции на день для экземпляра            | Практически `>= 0`          |
| `maintenanceRatePerDay`  | `double`                                | Пуассоновская интенсивность событий обслуживания на день для экземпляра         | Практически `>= 0`          |

## FakeDataHyperParams

| Параметр          | Тип                          | Описание                                                 | Ограничения    |
|-------------------|------------------------------|----------------------------------------------------------|----------------|
| `typeRootCount`   | `std::uint32_t`              | Число независимых корневых деревьев типов для генерации  | `>= 1`         |
| `typeTree`        | `TypeTreeHyperParams`        | Гиперпараметры генерации дерева типов объектов           | См раздел выше |
| `objectTree`      | `ObjectTreeHyperParams`      | Гиперпараметры генерации дерева объектов из дерева типов | См раздел выше |
| `instanceTree`    | `InstanceTreeHyperParams`    | Гиперпараметры генерации деревьев экземпляров            | См раздел выше |
| `eventGeneration` | `EventGenerationHyperParams` | Гиперпараметры генерации потока событий                  | См раздел выше |
