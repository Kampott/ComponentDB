Отлично. Теперь нужно обсудить то, зачем вообще нужна эта C++ программа. Основная идея - сделать сервис расчета надежности.

Основная идея: Object задает лес объектов. Нужно уметь по корневому объекту уметь расчитывать надежность всеъ компонент дерева (то есть, среднее время
поломки).

Для это существуют:
1) Экземпляры - точная реплика одного дерева объектов по структуре. Экземпляров на каждый объект может быть много
2) События - происходит для конкретного экземпляра и имеют определенный тип. Самый важный - замена. Событие имеет тип замена <=> для Event есть строка
   в таблицe ReplacementEvent. Точнее, замена - это не конкретно EventType: замена может быть по поломке. профилактике и тп. Это всё задается EventType.
   Также заметь, что EventType привязан к ObjectType в отношение many-to-many - это не особо важно в нашем случае, но вдруг понадобится

Считаем для начала, что есть такое упрощение:
1) Если ломается любой узел дерева экземпляра, то это означает, что ломается все дерево экземпляра (то есть, нету параллельных компонентов)
2) Сичтаем, что события внезапные

С такими ограничениями получается, что расчет будет происходит по распределению Пуассона, что сильно упрощает формулу для начала.

Также важно: ты можешь сделать предположения и сам решать, какие типы событий точно существуют для любого типа объекта. То есть, ты можешь в рамках
обдумывания условия и способа исполнения задать где-то хардкод списка типов событий
